# Prototype behaviour notes (X-1)

`medynium-prototype.html` (this folder) is a behaviour reference, not the visual target (UI rule 9). This file maps every behaviour in it to a screen of the real app, or records that it was dropped on purpose. No styling was ported.

| Prototype behaviour (function or element)                                                   | In the real app                                                                                                              | Where                                                       |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Navigation and views (`renderNav`, `setView`)                                               | Left nav, bottom tabs on phones; role-aware (Admin for admin doctors only)                                                   | `(workstation)/components/nav-rail.tsx`, `bottom-tabs.tsx`  |
| Dashboard worklist with change flags (`viewDashboard`, `flag`, `flagsHTML`)                 | Worklist table, flags as chips with icon and text                                                                            | `dashboard/`, `components/shared/chips.tsx`                 |
| Patient list (`viewPatients`)                                                               | Searchable, sortable, pageable table in the URL                                                                              | `patients/`                                                 |
| Patient 360 with tabs (`viewPatient`, `tabBody`)                                            | Header plus seven sections chosen by `?tab=`                                                                                 | `patients/[patientId]/`                                     |
| Lab chart (`chart`)                                                                         | Custom SVG trend with reference band, keyboard points, text summary and table                                                | `labs/`                                                     |
| Knowledge search (`viewKnowledge`, `kForm`)                                                 | Search with a complete citation block, snapshot date, empty state                                                            | `knowledge/`                                                |
| Activity log (`viewActivity`, `log`, `store`)                                               | Server-side audit entries with filters and a steps expander                                                                  | `activity/`                                                 |
| Agent panel and scope pill (`renderScope`, `scopePill`, `agent`)                            | Collapsible panel, "Scope: name" or "No patient in scope"                                                                    | `features/agent-panel/`                                     |

## Behaviours the prototype lacked and the app adds

- Denied patient and missing patient render one state (SEC-05).
- Loading, empty, error with retry, rate limited and agent-unavailable states on every data screen.
- Saved views with preview and explicit approval (FR-22).
- Admin: users, entitlement editor, invites, platform health.
- Honest gap wording from one copy file (`src/lib/copy.ts`).
