# Component specs (X-4)

One row per organism: what it is made of, the states it ships with, how it works by keyboard, and its accessibility notes. All are shown in every state at `/dev/components`. States follow the matrix in `05-ux-design.md` section 7.3.

## Shared components (`src/components/shared`)

| Component                                    | Anatomy                                                 | States                                                                       | Keyboard                                        | Accessibility notes                                                                                                |
| -------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `DataState`                                  | Wrapper that picks one of the states below from a query | loading, empty, not found, rate limited, agent unavailable, error, populated | Retry is a button                               | Loading is `role="status"` with `aria-busy`; a progress note appears after 3 seconds                               |
| `EmptyState`                                 | Icon, title, optional help                              | empty                                                                        | none                                            | Title says why it is empty; text comes from `copy.ts`                                                              |
| `NotFoundState`                              | Icon, title, hint                                       | not found                                                                    | none                                            | One wording for denied and missing patients; never reveals which                                                   |
| `ErrorState`                                 | Icon, plain message, request id, Try again              | error                                                                        | Try again                                       | `role="alert"`; no stack trace; server text only for 4xx                                                           |
| `AgentUnavailable`                           | Icon, honest message, Try again                         | agent unavailable                                                            | Try again                                       | `role="status"`; shown in the panel and beside agent-backed controls only                                          |
| `RateLimited`                                | Icon, "Try again in N seconds", button                  | rate limited                                                                 | Button enables at zero                          | Countdown is `role="status"` and is text only, so it needs no motion                                               |
| `DataTable`                                  | Caption, header buttons, rows                           | populated (callers supply empty)                                             | Header buttons sort; links and buttons in cells | `<caption>` names it, `aria-sort` on the sorted column, `aria-current` on a highlighted row; no row click handlers |
| `TagChip`                                    | Icon plus label                                         | one per tag                                                                  | none                                            | Meaning is text and icon shape, not colour alone (NFR-10)                                                          |
| `FlagChip`, `RouteChip`, `StatusChip`        | Icon or text plus label                                 | n/a                                                                          | none                                            | Outcomes always have text                                                                                          |
| `StepsList`                                  | Ordered list of steps with status icon                  | running, done, failed                                                        | none                                            | Polite live region, status also in screen-reader text                                                              |
| `StatTile`, `ValueWithSource`, `PageHeading` | Label and value; value, date and source; title row      | n/a                                                                          | none                                            | Description-list markup for tiles                                                                                  |
| `CopyLink`                                   | Label, read-only field, Copy                            | idle, copied                                                                 | Tab to field and button                         | Field selects on focus; "Link copied" announced politely; manual copy still works if the clipboard is blocked      |
| `ThemeToggle` / `ThemeProvider`              | Cycling button; class on `<html>`                       | light, dark, system                                                          | Button                                          | The label names the current choice and the next; no flash before paint                                             |

| ---------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `AnswerView` (`features/evidence`) | Route chip, Why? button, short answer, statements, conflicts, limits | populated, honest gap, conflict                                      | Every reference is a button                                               | Region labelled "Answer"; the gap uses fixed wording and never "no risk"; AI synthesis always shows the hedge     |

## Templates

| Template          | Behaviour                                                                                                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shell             | Skip-to-content link first; `<nav aria-label="Main">`; `<main id="main" tabindex="-1">`; synthetic banner above the top bar; assistant and drawer lazy-loaded; icon nav at 768 to 1279 px, bottom tabs under 768 px |
| Patient workspace | Gate then header, tab bar, content. Tab bar is a `<nav>` of links with `aria-current="page"` and scrolls sideways inside its own box on phones                                                                      |
| Dialog            | Title and description wired to the dialog; Close button named, 44 px on phones and 36 px elsewhere; placement `center`, `right` (drawer) or bottom                                                                  |

## Rules every component follows

- No hover-only content; tooltips are not used.
- Visible `:focus-visible` outline, set globally.
- All system wording comes from `src/lib/copy.ts`; dates, numbers and money from `src/lib/format`.
- Motion is opacity and transform at 150 ms or less and is switched off by `prefers-reduced-motion`.
